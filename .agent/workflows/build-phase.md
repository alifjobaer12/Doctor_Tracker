description: Implement the next unfinished phase from docs/10-implementation-plan.md
---
1. Read `AGENTS.md` and the relevant `docs/*.md` files for the phase.
2. Open `docs/10-implementation-plan.md`; find the first phase with unchecked items.
3. Write a short plan: files to create/change and the order.
4. Implement the phase, following `.agent/rules/` for backend/frontend.
5. Run lint, type-check and build for changed packages (and tests if present). Fix all errors.
6. Run `/verify` for anything user-facing in this phase.
7. Tick the completed items in `docs/10-implementation-plan.md`.
8. Commit with a Conventional Commit message summarizing the phase.
9. Report: what was built, how it was verified, any assumptions made.
